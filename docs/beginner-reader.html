开卷 · 人人可读

这本书在讲一件什么事？

四马古车：书名「御舆」——驾驭一辆车，也驾驭一个 Agent

大模型很聪明，但让它真正替你干活，还需要一整套"驾车"的 装备——这本书把这套装备拆开给你看。不用先懂编程，跟着图往下走就行。

罗盘：从「陪聊」到「干活」，换一种瞄准方式

权限管线 — Agent 的护栏

闸门：危险操作先过一道勾选的护栏

钩子系统 — Agent 的生命周期扩展点

挂钩：在人生节点上，给它装上小动作
