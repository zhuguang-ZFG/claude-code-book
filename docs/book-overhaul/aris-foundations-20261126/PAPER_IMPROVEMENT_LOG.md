## 第一轮审读与修订

冻结当前工作区源码与上一轮最终 HTML/PDF 为 `round0`，没有用 HEAD 覆盖未提交内容。完整报告见 [第一次审读](review1.md)，精确提示和身份字段保存在同目录的文本与 JSON 文件中。

评分 6.5/10，结论 Almost。三项主要问题为固定 seed 实验重复重置随机状态、束搜索被说成全局最优、六张技术图缺少可解释标签。修订如下：

- 连续抽样改为每段只初始化一次 RNG；通过独立 CDF 计算检查序列，补极小温度、并列最大值、零质量、采样区间边界的回归。
- 束搜索明确从当前保留路径中扩展和剪枝；删除行业采用率和“概率等于任务质量”的无依据概括。温度极限区分唯一与并列最大值，top-k 说明不同实现的并列边界。
- 章节开头改为可复现样本或明确假设，删除未证实的故障叙述。区分 Unicode 码点、字素簇、字节和 token；修正 Python 字符串截断与严格 UTF-8 解码的说法。
- 注意力表改为每层、每查询头的有效位置对；补 FlashAttention 的 IO 与反向重计算范围。KV 公式限定普通完整历史缓存，注明滑动窗口和 MLA 的结构差别。
- 单次窗口、累计输入、输出预留和缓存单价分开计账；会话脚本把工具回执 4 800 与助手历史 1 500 分列，零调用输出零费用，负预算输入被拒绝。
- 六张图加入真实样本、步骤、坐标与单位，以及 SVG 可访问名称和描述。概率图与 KV 图由 Matplotlib 按示例数值生成，图内保留文本；其他图为原创 SVG。
- 缩短手机采样表表头，安排参数换行，对本章短表和短列表局部保留分页。标题、稳定块 ID 和插图引用保持不变。
