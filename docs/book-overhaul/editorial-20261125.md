- Fork 示例：沿用 62,000 token 前缀、三个子请求、每个请求 200 token 指令的假设，统一计算口径。请求输入合计 186,600 token；共同前缀只计一次时，不同内容合计 62,600 token；重复内容为 124,000 token，占 66.5%。该比例不是 token 总量或费用降幅。相应 Mermaid 图与章首导读也同步收紧措辞。
- T3 Code：十八章导语改为具体操作与问题；导读卡分别填写问题、成果、适用范围和一句话说明，替换重复章节标题的模板。第 1、16、17 章压缩重复解释，区分 command 确认、事务提交、副作用执行与收尾。
- LLM：按前言已有的示例价格澄清缓存读取仍计费，保留显存和账单数据。Omp、Pi 前言分别对齐合集卷三、卷四；Vibe Coding 的前置阅读指引改为提示词工程所在的卷十。
- 派生内容：重新生成知识卡、样章、入门读本与搜索索引；刷新第 1、4、7、9、15 章的视频内容包，使其中摘录的说明和要点与当前书稿一致。
