## 两个项目可以成为同一个系列

适合纳入的是 `vibe-coding-101-course` 的大模型课程，与本仓的 Agent 书籍形成互补。前者回答模型怎样工作、应用怎样实现和验证；后者解释具体 Agent 怎样运行、扩展和恢复。提示词新册负责把任务、材料、工具与验收条件组织起来，帮助读者从理解模型走到实际协作。

建议使用“大模型与智能体工程”作为上层系列名。大模型课程仍是一条完整学习路线，不缩成只讲基础的前置读物；Agent 各册也保留独立上手入口。读者可以按目标选择，不必顺序读完全部书。

| 内容线 | 对应内容 | 读者要解决的问题 | 在系列中的位置 |
| --- | --- | --- | --- |
| 模型与应用工程 | 《大模型：从入门到精通》五阶段三十章 | 模型如何生成、检索与工具怎样接入、如何训练和交付 | 基础与应用工程主线；训练是可选深入路线 |
| 任务与协作方法 | 《提示词工程：从提问到 Agent 协作》 | 如何组织要求、选择上下文、比较修改效果、交接长任务 | 通用方法专册，连接模型课程与工具实战 |
| Agent 实战与机制 | 御舆、Omp、Pi、OpenCode、DeepSeek Harness、Hermes、Codex CLI、Kimi Code | 如何使用和扩展具体工具，其实现为何产生这些行为 | 按工具与问题选读；当前入口见[产品表](../../yuyu-book/PRODUCTS.md) |
| 编程项目实践 | 现有 Vibe Coding 内容 | 如何将需求变成可运行、可检查的程序 | 补充练习路线，沿用原来源与授权说明 |

`dmx` 工作区还包括参考仓库、视频工程和发布工具。它们分别作为资料、配套媒体和制作设施管理；本次系列定位针对课程内容，没有将整个工作区都登记为自有分册。

## 新册与现有课程怎样分工

| 主题 | 大模型课程已有内容 | 提示词新册增加什么 | 工具分册继续负责什么 |
| --- | --- | --- | --- |
| 任务说明 | C02 的目标、材料、约束、输出与核对 | 把含糊需求改成可执行任务，处理冲突要求、追问与多轮修改 | 项目说明文件如何被具体宿主加载 |
| 示例与结构化输出 | 指令学习、JSON、引用合同 | 选择正反例、避免示例泄漏、区分格式正确与语义正确 | 某个 CLI/API 的真实字段、事件和版本差异 |
| 上下文与检索 | C14–C15、C19–C20 的切块、检索与状态 | 对同一任务比较材料选择、排序、摘要与交接，记录实际送入的输入 | 内存、会话、缓存、恢复的源码机制 |
| Agent 与工具 | C16、C21 的工具回执、循环与方案选择 | 写明动作权限、停手条件、重试与职责分工，再用宿主设置落实 | 安装、权限规则、Hook、MCP、ACP 与插件生命周期 |
| 评测 | C18、C22 的冻结问题、失败分层与质量/延迟/费用 | 提示版本对照、重复试验、跨模型迁移及提示变更回归 | 宿主自身测试、协议与系统边界验证 |
| 工程交付 | C29–C30 的干净环境、发布与回退 | 交付提示、上下文清单、运行设置、评测和接手说明 | 软件构建、部署、进程管理和运行时排错 |

共同术语先保持一致：模型不等于聊天产品，提示不等于权限，工具请求不等于完成回执，来源存在不等于支持结论。每册首次出现时就地解释，跨书链接用于进一步阅读。

## 三条阅读路线

| 读者目标 | 建议路线 | 可交付成果 |
| --- | --- | --- |
| 先把日常任务做好 | 大模型 C01–C04 → 提示词第 1–6 章 → 按需补上下文和评测 | 一份有依据、能核对的任务结果 |
| 使用 Agent 完成编程任务 | 提示词第 1–4 章 → 自选 Agent 的上手章节 → 提示词第 7–18 章与该工具对应机制 | 可复做的任务、工具轨迹和测试结果 |
| 开发大模型应用或研究运行时 | 大模型 C05–C22 → 提示词评测专题 → 按问题查 Agent 源码册；训练另读 C23–C26 | 能定位失败环节的应用与改进记录 |

这些是跨书选读路线，不改动大模型课程内部的先修关系，也不意味着跳读后通过了它的能力门。C27–C30 的多模态与独立交付按原课程要求继续完成。

## 共同系列如何落地

第一步是统一目录、内容定位、术语和相互引用。两边继续各自构建：大模型课程维护 A5 正文与分离答案，本仓维护 Agent 分册与提示词册；各自的产物、版本和来源仍可追溯。现有“驭者·Agent Harness”视频可以保留为子系列。

封面后续增加共同系列名，各书保留自己的书名与视觉特点。电子书必须能独立阅读，不能把关键步骤藏在另一本书或在线链接里。公开跨仓链接固定到可用版本；本地绝对路径只用于工作区导航，不作为发布页面的依赖。

提示词册现已完成中文前言、十八章、四篇附录与原创离线练习，按技术试读版接入独立 HTML/PDF/EPUB 构建，入口见[本册说明](../../prompt/README.md)。模型 A/B、跨模型迁移和独立读者验收仍待实测；大模型课程继续在原仓库维护。
