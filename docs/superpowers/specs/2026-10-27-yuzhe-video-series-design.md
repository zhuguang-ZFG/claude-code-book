# 驭者·Agent Harness 视频系列设计

日期：2026-10-27

参考风格：[awesome-opus5-5-videos](https://github.com/yihui-dev/awesome-opus5-5-videos)  
账号：小电讲电路  
系列名：驭者·Agent Harness

## 1. 目标

把开源书稿整理成可发布视频，双形态分发：

- B 站：横屏长讲（深度）
- 抖音 / 小红书：竖屏短动效（传播）

系列定位为「基于开源书稿」，置顶目录帖，片头/片尾与简介标明出处与原书链接。

## 2. 范围（样片阶段）

- 先做第 01–04 章（基础篇）为样片批次。
- 制作与发布采用 **A. 样片先行**：只先完整做出第 01 章（1 条长讲 + 1 条短片素材），用户过片后再批量 02–04。
- 第 05–15 章与附录不在本阶段。

## 3. 成片形态

### 3.1 B 站长讲（每章）

- 时长：15–20 分钟
- 画幅：横屏 1920×1080
- 结构：封面 → 开场钩子 → 原理动画 → 关键代码走读 → 口诀/小结 → 片尾（出处 + 合集引导）
- 口播：沉稳男声（不使用晓晓·轻柔）
- 字幕：默认中文 SRT；需 B 站封面、章节时间点、合集「驭者·Agent Harness」

### 3.2 抖音 / 小红书短片（每章）

- 时长：30–60 秒
- 画幅：竖屏 1080×1920
- 结构：前 3–5 秒 Opus 风格动效钩子 → 口播讲清一个机制 → 片尾轻带「完整版在 B 站」
- 同一章短片可复用到抖音与小红书（文案可微调）
- 小红书保持人感节奏，少发、不批量脚本刷量

## 4. 画面与动效

- 长讲：深色工程风；架构框图、对话循环、工具调用路径等动画须带真实模块名与书稿中的关键数字/结构，不做空泛示意图。
- 短片钩子：HTML/Canvas/SVG（或同类）代码驱动动效，参考 Opus 合集的病毒短片质感；隐喻可用「驭手 / Harness」。
- 统一视觉：系列名条、章号徽章、片尾「基于开源书稿 · 完整版 B 站」。

## 5. 制作流水线

1. 从对应章 Markdown 抽出长讲大纲 + 短片钩子脚本。
2. 长讲：讲解动画 + 代码高亮走读 + 男声配音 + SRT + 封面。
3. 短片：动效钩子录屏 + 口播段拼接。
4. 用户审第 01 章样片；通过后批量 02–04。
5. 发布：B 站先上长讲并入合集；抖音/小红书按人感节奏发短片；置顶系列目录（含开源书链接与进度）。

## 6. 发布与验收

### 6.1 样片交付物（第 01 章）

- B 站可投稿长讲成片 1 条
- 抖音/小红书可用短片成片 1 条（同素材可略改编）
- 封面、SRT、简介/标签草稿、出处文案

### 6.2 验收标准

- 时长落在约定区间
- 出处与系列信息齐全
- 动效清晰不糊，口播清晰
- 无技术硬伤（与书稿关键机制一致）
- 过审后再开 02–04

## 7. 明确不做（本阶段）

- 不一次做完 15 章
- 不沿用晓晓女声
- 不做无书稿依据的夸张科普
- 小红书不批量连发

## 8. 下一步

用户确认本规格后，编写实施计划（writing-plans），再开始第 01 章样片制作。
