# R4 衍生物料——规格（趣味可读）

日期：2026-11-03 · 前轮：R3 记忆点工程（PR #5 → `6212391`）已合并。

## 1. 目标

把书里的记忆点搬出书外，做成可离线打开、可直接进视频流的成套衍生料：

1. **知识卡 ×15**（3:4）：每章一张自绘 SVG 卡——章徽隐喻 + 开门一句话 + 难度定位 + 三句话带走；配套索引页 `docs/cards/index.html`。
2. **样章精排单页**：`docs/sample-chapter.html`，选第 2 章（对话循环，全书心脏），题图 + 钩子 + 精排正文 + 回收卡尾，单文件零外链。
3. **视频封面草案 ×5**（16:9）：`docs/video/ch01…ch05/cover-draft.svg`，handraw 风格，复用各章既定 plate 隐喻，作 ch02–05 成片封面与 ch01 封面改版的设计底稿。
4. **unslop 去 AI 味审计**：`scripts/build_site_portal.py`、`scripts/build_illustration_gallery.py`、`scripts/build_beginner_reader.py` 三个生成器过九遍工序中的文案/布局/细节三遍（改生成器脚本后重生成 dist，不手改产物）。

## 2. 数据与依赖（零新隐喻、零锚点平移）

- 卡片文案直接抽自章节 md：`> **开门一句话：**` 行、`**难度定位：**` 行、`> **三句话带走：**` 行（R3 产物，格式固定可正则）；隐喻取 `yuyu-book/notes.json`（20 条 keeper notes）。
- 构图沿用各章章内 plate（dist 176 幅）的既定隐喻，不发明新图形系统。
- 本章只增 `docs/` 产物与 `scripts/` 生成器，**不动 15 章 md、不动 `yuyu_book/` 管线** → 登记锚点零平移。

## 3. 硬契约

| 物料 | 尺寸 | 格式 | 颜色 | 文字 |
|---|---|---|---|---|
| 知识卡 | 750×1000（3:4） | SVG | 仅 `currentColor`/CSS 变量 | 卡内文字≤120 汉字（钩子+难度+回收原文） |
| 样章页 | 自适应 | 自包含 HTML | 页面级 CSS 变量 | 全章正文 |
| 封面草案 | 1600×900（16:9） | SVG | 同上 | 标题+一句钩子 |
- 零第三方 logo/字体/图链；SVG 内零脚本零动画事件（与 check_mermaid 同哲学）。
- 生成器全部幂等：重跑无 diff。

## 4. 不做

- 不进五道闸管线（standalone 脚本），但重生成产物随 PR 提交。
- 不改 `docs/video/**` 既有 md 文档；封面草案是**新增文件**。
- 不做英文知识卡（视频物料面向 B 站，中文优先；en 侧留待需求）。
- unslop 不动版式主结构，只清 AI 腔文案与模板化细节。

## 5. 验收

- `docs/cards/` 15 张卡 + 索引页可离线打开，卡上文字与章节原文逐字一致。
- `docs/sample-chapter.html` 单文件离线可开，正文来自 dist 渲染产物（同一管线）。
- 5 张封面草案含各章 plate 同源隐喻。
- 三生成器 unslop 审计留痕：改动后重生成，产物 diff 只含文案/细节。
- 五道闸全绿（本章理论零影响，全量复跑为准）；账本第 57 条双语（末尾 `构建器测试 N 项全绿`/`N builder tests green`）。
