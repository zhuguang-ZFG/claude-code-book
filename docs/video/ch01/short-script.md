# 第 01 章短片钩子分镜与口播脚本｜驭者·Agent Harness

> 平台：抖音 / 小红书竖屏 1080×1920  
> 结构：0–5s Opus 风格 HTML/Canvas 钩子 → 口播讲清一个机制 → 片尾引导  
> 口播音色：沉稳中文男声（禁用晓晓·轻柔）  
> 单一机制：为什么需要 Agent Harness，而不是简单 API 封装  
> 出处：基于开源书稿《驭者：驾驭 Agent Harness》第 01 章 §1.1

---

## 1. 钩子分镜（0.0–5.0s）

可落地为单一 HTML/Canvas 文件（建议路径：`video/ch01/assets/ch01-hook.html`）。画布竖屏 1080×1920，深色工程风底板，字体与系列视觉统一。

| 时间 | 画面 | Canvas / 动效提示 |
|------|------|-------------------|
| **0.0–1.5s** | 多枚对话框气泡自底向上堆积；右侧人手图标循环「复制 → 粘贴」到气泡与终端之间 | `bubble` 粒子上浮叠加；`hand` sprite 循环 2 次；节奏偏快，制造「人当胶水」压迫感 |
| **1.5–3.5s** | 气泡被吸入画面中心，收束成发光中枢节点；自中枢连出四路射线，端点分别标 **Tool / FS / Git / Shell** | 力导向收束动画；四路路径用贝塞尔线生长；模块名用书稿真实称谓，不做空泛图标堆砌 |
| **3.5–5.0s** | 中枢脉冲一下；标题字落版：**Agent Harness · 驭者**；左上角轻量系列条「驭者·Agent Harness」 | 标题自缩放 1.15→1.0 + 轻微模糊→清晰；落版后静帧 0.3s 切口播 |

钩子无口播；可加短促电子音效（可选，后期合成时再定）。

## 2. 口播全文（钩子之后）

**音色：** 沉稳男声。语速中偏稳，专有名词略顿。

### 主体（机制说明，≤120 字）

很多人以为 Agent Harness 就是 API 套壳加 while 循环。生产里超时、格式错、权限乱、上下文会满，理想假设会被逐个打破。简单封装像装遥控器；Harness 是能跑、能停、能诊断的整车。模型是马，Harness 是缰绳和鞍具。

## 4. 时长自检

统计口径：口播连贯稿去掉空白后的字符数；按 **4 字/秒** 粗算口播时长；钩子固定 **5.0s**。

| 项 | 值 |
|----|-----|
| 主体字数（去空白，不含片尾句） | **114**（≤120） |
| 片尾句字数（去空白） | **26** |
| 口播总字数（去空白） | **140** |
| 口播估时 | 140 ÷ 4 = **35.0s** |
| 钩子 | **5.0s** |
| **成片估时** | **40.0s** |
| 目标区间 | **30–60 秒** → ✅ 落入 |
