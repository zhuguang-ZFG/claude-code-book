## 口播

改了 settings.json，重启——还是老样子。你没改错值，你改错了层。配置不是一个文件，是六层岩：插件、用户、项目、本地、CLI、企业，越往上越大。盖住不等于删掉，所以挑层比改值要紧。猜一猜：权限数组会被上层覆盖掉吗？不会。数组只拼接去重，像钥匙圈，每层挂自己的，谁也摘不掉别人的。要撤销得用 deny 明说。最后一刀：六层里有一层，安全上系统根本不看它——项目那层，因为它来自别人的仓库。完整版在 B 站合集「驭者·Agent Harness」。

## 画面要点

- 钩子：改 model → 重启 → 弹回原样（红叉）→ 取芯柱抽出六条色带
- 六层岩：自下而上逐层亮起 + 人话标签（插件/用户/项目/本地/CLI/企业）
- 盖住 ≠ 删掉：上层半透明压下，下层字仍可见
- 猜一猜：数组会被覆盖吗？→ 揭晓「只挂不摘」
- 钥匙圈：逐层挂钥匙，一把不掉；空数组挂上去＝灰（无效）
- 收刀：陌生仓库的告示牌钉上自家墙 → projectSettings 格子灰掉
- VS：一个文件 vs 六层岩
- 水印：小电讲电路 / 驭者；无吸粉冲击文案
