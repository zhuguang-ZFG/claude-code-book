# 前言

<!-- block: llm-front.b-opening -->
Agent 工程师每天都会碰到一组看似分散的问题：为什么这段中文按 token 计费比英文贵；为什么同一个提示每次生成的 JSON 略有不同；为什么上下文窗口标着 200K，塞到一半就开始变慢、变贵、漏掉关键信息；为什么 KV cache 会决定并发数；RAG 和 Agent 记忆到底怎么分工。

这些问题的答案不在某一款 Agent 的配置里，而在模型这一层。本书用可以在一台普通笔记本上运行的 nano 尺寸例子，把这些机制拆开：token、embedding、注意力、Transformer、采样、上下文成本、预训练、后训练、推理部署、RAG、工具调用、思维链、评测与蒸馏。全书不训练 SOTA 模型，也不要求 GPU；目标是让 Agent 工程师能读懂模型卡、算清预算、判断一项优化是否值得做。

## 这套书在讲什么

“大模型与智能体工程”系列有几条入口：

- [《御舆：解码 Agent Harness》](../00-前言.md)从对话循环、工具、权限、上下文和记忆讲 Agent 的整体结构；
- [《提示词工程》](../prompt/00-前言.md)讲任务说明、材料组织、工具协作与评测；
- OpenCode、DeepSeek、Hermes、Codex、Kimi、Pi 等分册讲具体 Harness 的实现；
- 本卷回到模型本身，解释 Harness 每天调用、计费和约束的那个对象。

如果你已经会写 prompt、会调 API，但没系统学过 attention 推导，本卷按“机制 + 最小实现 + Agent 工程落点”来写。每章只引入必要的数学，代码尽量限制在 Python 标准库或最小依赖内。

## 怎样读

- **先解决眼前问题**：按上表选一章，先跑示例，再读解释；
- **按原理主线**：第 1–16 章按顺序读，建立从 token 到多模态的完整链路；第 7 章算训练账，第 8–9 章讲怎样把基座改成助手，第 10 章算服务端成本，第 11–12 章讲 RAG 与工具协议，第 13 章讲测试时计算，第 14 章讲怎么判断是否变好，第 15 章讲模型怎样看图，第 16 章用来查词；
- **按工程任务**：第 1、6 章处理预算与上下文，第 2、11 章处理检索与语义相似度，第 5、13 章处理采样、投票与稳定性，第 7–9 章处理训练、微调与对齐，第 10–12 章处理部署、RAG 与工具调用，第 14 章处理评测与蒸馏，第 15 章处理截图、UI 与文档识读；
- **只想知道概念**：先读每章开头的场景和末尾的“常见翻车”，再回到中间看机制。

示例都在 `llm/examples/` 下，使用 Python 3.12+ 的标准库。命令从仓库根目录执行：

```bash
python llm/examples/bpe_demo.py

python llm/examples/transformer_demo.py
python llm/examples/sampling_demo.py
```

不需要模型账号、API key 或 GPU。示例输出是教学数据，不是厂商 benchmark；真实 token 数、价格、显存占用要换成目标模型和当前价格重算。

书中的章徽、篇题和封面是手绘墨线 SVG，源文件随仓库保存在 `yuyu-book/illustrations-agents/`；它们只用 `currentColor` 描线，能随暗色和纸面重新上墨，不嵌入外部图片。

## 证据边界

书中的技术断言尽量钉到具体版本文档或论文；来源、快照日期和许可登记在 [`yuyu-book/sources-llm.json`](../yuyu-book/sources-llm.json)。GitHub 来源固定到完整 commit，见 [`llm/facts/source-lock.json`](facts/source-lock.json)。

已经实际运行的内容：十五个示例脚本、构建检查、示例测试。尚未进行的内容：真实模型上的采样对比、生产 tokenizer 的跨模型计数、真实预训练/微调/对齐实验、长上下文质量实验、显存与吞吐压测、真实多模态模型的识读对比。这些缺口在正文中标注为练习或待测，不用“通常”“一般认为”替代证据。

生产 tokenizer 的计数与本书玩具 BPE 不同；书中引用 toy token 数时都会标明。厂商的价格、窗口和模型结构会变化，第 6 章的公式和输入参数比具体数字更值得保留。

## 开始

从[第 1 章](ch01.md)开始：先看一段中文怎样变成字节、再变成 token，以及为什么“字数”不能直接当预算。读完后，你会知道下一次该量什么，而不是只记住一个比例。
