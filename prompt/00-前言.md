# 前言

<!-- block: prompt-front.b-opening -->
一份可以交接的 AI 任务，需要说明用途、提供依据、检查结果，并留下下一次能够继续使用的记录。本书用青禾工作坊的同一组材料，带你把这些工作逐步做出来。

你可能已经试过给 AI 增加角色、列出步骤、要求它仔细检查。有些回答因此更合用，有些仍然漏掉日期、误读表格，或声称完成了并未执行的动作。这时先查它实际收到了什么、哪一步出了问题、谁能检查那一步，通常比继续添加强调词更有帮助。

本书从一份活动说明开始讲提示词工程。先用提示说明要做什么，再把支持任务的材料交给助手；需要行动时接入工具，拿到结果后检查是否可用。每次留下的记录，供后续修改和交接使用。读者可以一步步完成这些工作，无须一开始就搭起复杂系统。

## 从两份通知读到一个小程序

贯穿案例叫“青禾工作坊报名助手”。最初只有活动通知与报名规则，读者需要把时间、地点、费用和候补办法整理清楚。随后出现正式修订、未经核实的聊天、旧答复和夹带指令的备注。材料变多后，问题不再只是怎样提问，还包括应该选哪份、信到什么程度、缺了什么。

后半册用一个本地名额程序继续练习。正式人数等于容量时，新申请进入候补；取消正式名额后，候补队首递补。我们沿这些规则检查边界条件和重复动作，再尝试把审查与修复分开交代。程序只处理教学数据，没有真实报名、支付或通知服务。

工作坊、人物、材料日期和练习回执均为原创虚构教学内容。书中人工编写的答复会标明为示例，不能当作模型实测。离线程序与检查工具有实际运行记录；模型 A/B 和跨模型实验的未测范围在正文及附录中保留。

## 选择适合自己的读法

第一次系统整理 AI 任务，可以按第 1–8 章顺序读。你会得到任务说明、事实核对、输出约定、材料清单和会话交接记录。前两篇不要求编程；遇到命令时，可以先用手工方式完成同一项检查。

已经使用代码助手的读者，可以先看第 1、7 章，确认任务与上下文的共同约定，再读第 9–14 章。这里关注中间结果、工具回执、修复范围和协作，不重新讲各款 Agent 的全部安装流程。具体工具的机制与固定版本入口在附录 C。

需要比较提示修改的人，重点读第 15–18 章。先冻结题目与判据，再保存每次响应，最后判断哪些变化值得采用。相同题目重复运行，可以观察波动；换成陌生材料，才能进一步检查方法是否迁移。两者不能互相替代。

| 想先解决的问题 | 建议起点 | 可以留下的成果 |
| --- | --- | --- |
| 回答总和我想的不一样 | 第 1–4 章 | 用途、材料、输出与检查条件明确的任务 |
| 资料很多，回答却仍用错版本 | 第 5–8 章 | 可追查的实际输入与交接记录 |
| Agent 说完成了，我不知道怎么验收 | 第 9–14 章 | 动作边界、真实回执与回归结果 |
| 新提示看起来更好，是否应该替换旧版 | 第 15–18 章 | 保留失败与成本条件的比较记录 |

## 跟做时保存什么

建议为自己的练习准备一个独立目录。原始材料保留原名，自己的任务与回答另存文件，避免直接覆盖。每次修改至少留住使用的材料版本、提示文本、原始输出和核对结果。文件名可以很朴素，例如 `task-v1.txt`、`answer-v1.txt`、`review-v1.txt`。

书中的命令若未另作说明，从书籍仓库根目录执行。这个目录里能看到 `prompt/`、`scripts/` 和 `yuyu-book/`。命令中的 `.scratch/` 用于练习输出。具体运行要求集中在[离线练习说明](examples/README.md)，首次运行前先确认 Python 版本。

不开通模型服务，也能完成任务改写、材料取舍、人工核对和本地业务检查。使用自己的模型环境时，要保存实际产品、模型标识和可设置参数。聊天产品不提供的信息可以写“不可见”或“不可设置”，不要替它猜一个版本或配置。

读到示例答案前，先自己做一遍，再核对其中的依据。留出题等到方法确定后再打开；如果看过答案后又调整了提示，就记下这次暴露，并准备新的验收题。

## 这本书在系列中的位置

“大模型与智能体工程”系列保留几条各有入口的路线。《大模型：从入门到精通》解释模型原理、应用实现、训练与交付；本书展开任务、材料和协作方法；各款 Agent 分册说明具体工具怎样加载规则、调用工具、管理会话与恢复。

遇到具体问题时，可以沿实际证据选择阅读位置。提示写了“不要修改文件”，要接着查宿主是否限制写入；回答带有引文，要回到材料核对它能否支持结论；程序通过一组测试，要确认那些测试覆盖了哪些条件。这样能够判断下一次该查提示、材料、代码还是工具配置。

本版为中文技术试读版。正文和离线练习提供完整阅读路线，已有运行记录与尚未进行的模型实验分别列明。你可以从[第 1 章](ch01.md)开始，先把一句“帮我处理一下”改成别人也能照着完成的任务。
