# 附录 D：术语、资料与进一步阅读

<!-- block: prompt-apxd.b-opening -->
术语用于指出任务中的具体部分。本附录按青禾案例解释常用词，并给出回查章节；遇到产品专有行为时，仍以对应工具和版本的资料为准。

## D.1 在当前任务里理解术语

<!-- block: prompt-apxd.b-terms -->

| 术语 | 在本书中的含义 | 回查 |
| --- | --- | --- |
| 提示 | 向模型交代任务、约束和输出要求的文字或消息 | 第 1、5 章 |
| 上下文 | 一次请求中模型实际能使用的指令、材料、历史和工具结果 | 第 7 章 |
| token | 模型按分词方式处理的文本单位，不与字符数固定对应 | 第 7、17 章 |
| 零样本 | 交代任务时不附该任务的示范输入输出 | 第 4 章 |
| 少样本 | 用少量示例帮助说明任务规律或格式 | 第 4 章 |
| JSON | 用字段、数组和类型组织数据的文本格式 | 第 3 章 |
| 工具回执 | 一次实际工具调用返回的状态、输出或错误信息 | 第 10 章 |
| Agent | 围绕任务调用模型、使用工具并接收结果的执行过程或系统 | 第 9–14 章 |
| Skill | 在支持它的宿主中组织可复用说明与资源的一种方式 | 第 12 章 |
| 项目规则 | 随项目保存的持续工作说明，如何加载由宿主决定 | 第 12 章 |
| 提示注入 | 外部内容试图让模型把其中的文字当作新指令执行 | 第 14 章 |
| 留出集 | 在提示开发和方案选择阶段没有使用、留到后续检验的题目集合 | 第 15 章 |
| 配对对照 | 在同题与对应重复次数下比较两个版本的结果 | 第 16 章 |
| 回归 | 修改后重新检查原先需要保持的行为，寻找新增失败 | 第 11、16 章 |
| 指纹 | 根据文件内容计算的标记，用于核对版本变化 | 第 7、18 章 |
| 幂等 | 同一操作重复执行时，不额外增加业务效果的性质 | 第 8、10 章 |
| 检索 | 从资料集合中找出与问题可能相关的内容 | 第 7 章 |
| 记忆 | 系统保存并可能在后续任务中重新使用的信息 | 第 8、17 章 |

一次操作是否具有幂等性，要看实际接口约定和状态变化。稳定的操作号可以帮助识别重复，但不会自动让所有工具安全重试。同样，文件已保存不表示产品一定会把它作为记忆读入下一次请求。

## D.2 本册的原始材料与程序

青禾活动通知、报名规则、修订、聊天摘录与失败场景均为原创虚构教学材料，ID 和变更关系见[材料记录](materials/CHANGELOG.md)。[练习说明](examples/README.md)提供输入导出、机械检查、名额程序与模型对照准备的命令。

案例中人工编写的通知和回执，只用于教学输入。离线程序的实际运行结果保存在[证据目录](evidence/README.md)。读者自行运行模型得到的响应应另外保存，不能与人工样稿混放后统一称为实测。

## D.3 沿系列继续阅读

本册聚焦如何说明任务、选择材料、核对结果和交接工作。模型结构、检索实现、训练和完整应用工程，可回到《大模型：从入门到精通》的相应课程。两条路线的分工和先修关系见[系列定位](../docs/series/README.md)。

第 16 章引用的大模型课程对照来自[固定版本 EVALUATION-04](https://github.com/zhuguang-ZFG/vibe-coding-101-course/blob/e74c7315bb8e72aa501e11ba4aef29a8efc66c17/book/llm/examples/assistant/EVALUATION-04.md)。该记录消除了 extract 的输出字段冲突，但修前、修后均为 5/8；其中包含非模型边界检查。它支持原记录所述范围，没有在青禾案例中复跑。

具体 Agent 的使用和机制入口集中在[附录 C](appendix-c.md)。阅读时先确认版本和验证层次，再把方法带回自己的任务。出现新版本或新材料后，按实际变化重新检查相关行为。
