# 判据与答案分开保存

[逐题判据](criteria.json)用于读完输出后的人工复核，不进入导出的模型输入。开发题可以边看判据边改提示；验证题在方案确定后运行；留出题到最终验收时再打开。打开过留出题或看过失败后继续调提示，就登记暴露并准备新的留出题。

评分先检查原始输出是否符合 JSON 约定，再逐条核对事实、依据、未知项、动作与回执。所有必需项满足才记 pass；存在错误记 fail；服务失败、无法获得响应记 error。错误也留在预定次数的分母中，并单列次数。不要把待评记录默认为通过。

D02 用于材料选择教学：完整材料和所选材料需要完成同样交付；摘要故意删掉必要时间，能正确承认不足，但不能获得“完整交付通过”。这是比较信息损失的开发题，不纳入默认的验证对照。

`lab.py check` 只检查字段、类型、引文是否出现在**实际提供的文字**中，以及这些只读任务是否出现行动记录。引文原文匹配不证明回答受引文支持。语义判断、遗漏、事实冲突和未经记录的实际行为需要人另查。练习文件中的回执是人工构造材料，不能说它们来自真实外部系统。

本轮的机械故障测试还包含非法 JSON、字段缺失、伪造引文、错误答案配正确引文、重复评审行、漏评和输出文件被改写。这些是工具单元测试，不计为模型题目或模型成功率。
