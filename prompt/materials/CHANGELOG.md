# 材料变更记录

2026-11-10：创建 1.0 教学材料包。材料内的 2025—2026 年日期属于虚构场景，不代表真实活动。材料文字、编号和程序均为本册原创。

N01-v1 给出首次通知；U01-v2 只修改活动时间；U02-v3 是留出题的容量修订。三份文件并存，便于练习按字段判断版本。R01-v1 定义名额程序的业务规则。

C01-v1、A01-v1 和 D01-v1 分别用于未核实消息、过期材料和错误示例；X01-v1 保留无法裁定的同批冲突；I01-v1 用于辨识外部文字中的伪指令；T01-v1 用于失败回执与任务恢复。L01-v1 提供新的借阅场景。

留出材料与答案在仓库中可读，只是教学上的隔离。导出工具按选定题目取材料，不会自动包含留出题或评分答案。已经读过留出题的读者应标记暴露情况，正式检验时换用新题。
