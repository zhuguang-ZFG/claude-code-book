# 名额、候补与取消规则

材料 ID：R01-v1。版本：1。发布：2026-11-01。发布方：青禾工作坊组织者。原创虚构教学材料。

R1：容量是大于等于零的整数，正式名单人数不得超过容量。容量为零时，新申请进入候补。

R2：每位参加者使用一个稳定编号。编号已在正式名单或候补名单中时，再次申请返回 duplicate，两个名单都不改变。

R3：在报名开放期间，新编号申请时，正式名单人数严格小于容量才可加入正式名单；满额则追加到候补队尾。本练习初始状态中，存在候补时正式名额必已满。

R4：取消正式名额后，如有候补，立即把候补队首移入正式名单；取消候补只删除该候补。编号不在任何名单中时返回 not_found。名单内顺序保留。

R5：容量、名单或申请字段非法时返回 invalid，原状态不变。非法包括布尔值充当容量、负容量、重复编号、名单交叉、正式人数超容量、存在候补却有空位、空白编号和未知动作。

本地程序只处理报名开放期间的一次名额状态转换，不处理真实身份认证、并发、时间截止、数据库、支付或消息发送。请求中 action 只能是 register 或 cancel；程序返回新的名单，不写外部系统。

正式通知的修改须指明修改项。更新只替换点名的字段，其他规则继续生效。无法确认哪份通知有效时，保留冲突并请组织者确认。
