# 前言

<!-- block: t3code-front.b-opening -->
这本书讲 T3 Code，一个开源的 coding agent 控制平面。它本身不回答问题、不改代码；它让 Claude Code、Codex、OpenCode、Pi 这些已经装在你机器上的 agent 有一个共同的入口，并把线程、权限、工作树和远程连接这些重复出现的问题收在一处处理。

理解它的关键，是先分清「谁在干活」和「谁在安排」。干活的始终是具体的 agent 与它背后的模型；T3 Code 决定哪条消息进哪个线程、哪次改动落在哪个工作树、哪一次命令需要人批准，以及手机上的一次点击怎样安全地变成服务器上的一次动作。

## 为什么单独写一册

Agent harness 的书通常从「模型怎样变成 agent」讲起。T3 Code 在官方内部文档里被当成 harness 之外的东西：它管的是很多 harness 的生命周期。把两者混在一起讲，容易把「provider 的协议细节」和「控制平面的编排决策」搅成一团。这一册只关心后者，遇到 provider 内部机制时会点到为止，并指明该去哪一册看。

## 这本书依据什么

所有机制陈述都钉在 `pingdotgg/t3code` 的固定提交 `3b3b662f` 上，来源逐章登记在末尾，附录 D 给出统一索引。官方文档写明的事实，直接陈述；由事实推出来的理解，会用「可以这么理解」「不妨把它看成」标出；文档没有写明的实现，不作断言。上游许可为 MIT，本书只做链接引用，不转载原文。

## 怎么读

第一篇建立全局：它是什么、怎么装上、provider 为什么是适配层、线程与消息怎样组织。第二篇转向掌控：权限四档、检查点与回滚、PR 交付。第三篇处理远程与信任：连接、鉴权、MCP、设备、秘密。第四篇拉到工程视角：事件溯源、性能约束、更新与排障。附录可以按需查阅。

如果你只想先跑起来，读第 2 章和第 4 章即可；如果你正在搭自己的 agent 平台，第 12、13、16 章最值得反复读。
