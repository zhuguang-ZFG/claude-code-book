# 附录 A：三张可直接抄的模板

## A.1 任务卡

```text
目标：谁拿这个结果做什么。

输入：
- 文件与编码
- 必填列 / 必填字段
- 样例文件路径

规则：
1. 空值与非法值怎么处理。
2. 重复怎样判定，保留哪一条。
3. 排序与分组。
4. 哪些字段不得公开。
5. 失败时的行为（报错、退出码、是否留下半成品）。

验收：
- 运行命令。
- 期望的终端输出。
- 一条否定条件（什么出现就算失败）。
- 缺输入时的行为。

回退：
- 上一版产物在哪里。
- 代码恢复到哪个提交。
```

## A.2 验收单

```text
[ ] 正常路径：一条完整记录生成正确结果。
[ ] 边界：空值、重复、未知值、超长文本。
[ ] 反例：私密字段未出现；缺输入不生成半成品。
[ ] 页面：手机宽度无横向滚动；长文本换行。
[ ] 回滚：旧产物可打开；代码可恢复到上一提交。
[ ] 记录：运行命令、实际输出、测试结果已写入 README 或提交信息。
```

## A.3 交接记录

```text
项目：一句话说明它做什么。
运行：从干净目录开始的命令。
输入：文件从哪来，哪些字段必填。
输出：产物给谁，放在哪。
边界：不得公开的字段、不得覆盖的文件、不得调用的服务。
已知问题：当前未修但已知的风险。
回滚：恢复哪个产物、哪个提交。
最近决策：三条，每条写原因、取舍、验证。
```
